# ЖК Family • Світло

Публічна статична сторінка фактичного стану світла та планового графіка підгрупи 2.2.

Сторінка не публікує адресу, номер квартири, ідентифікатори обладнання або внутрішню
телеметрію. `data.json` оновлюється детермінованим локальним publisher лише при змінах
фактичного статусу чи графіка.

Публічна адреса після ввімкнення GitHub Pages:

<https://setevoy2.github.io/family-svitlo/>
